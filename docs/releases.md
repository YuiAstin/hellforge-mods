Uploading (2026-11-16): zips built by `tools/package.py` from a clean export of the branch (`git archive`), never from a worktree (ignored files such as Ascalon's `sounds/` would be packed) and never after `tools/inigen.py` without checking the ini's diff (it drops sections it does not know). In Chrome a file is given to a page's upload field from the staged copy of the PC's `Releases/nexus` folder. Nexus: Files, the hidden "Add file" input, then "Update existing file" with the old one archived and the mod version matched. AyakaMods: `<mod page>/post-update`, "Release a new version".
